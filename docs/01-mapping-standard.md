# ATT&CK Mapping Standard

1. Define the incident or threat-actor scenario.
2. Break activity into discrete attacker actions.
3. Map each action to tactic and technique/sub-technique.
4. Record the evidence supporting the mapping.
5. Identify relevant detection data sources.
6. Identify useful mitigations and defensive controls.
7. Document confidence and reasoning.

The goal is evidence-backed TTP mapping, not a generic list of ATT&CK techniques.
