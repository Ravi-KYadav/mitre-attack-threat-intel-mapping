# Threat Intelligence Case Backlog

Planned mappings are promoted to completed cases only when the source behaviour and ATT&CK mapping can be supported by evidence.

| ID | Scenario | Primary output | Status |
|---|---|---|---|
| TI-001 | Phishing / Initial Access | Tactic + technique + detection source | Planned |
| TI-002 | PowerShell execution | Technique + telemetry + mitigation | Planned |
| TI-003 | Credential access behaviour | Technique + evidence + defensive control | Planned |
| TI-004 | DNS-based command and control | Technique/sub-technique + network telemetry | Planned |

## Completion standard

Each completed case should identify the observed behaviour, ATT&CK mapping, evidence, relevant data sources, detection opportunities, mitigations and confidence/limitations.
